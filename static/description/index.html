Один install — отримуєш все необхідне для роботи табору від реєстрації до звіту керівника.

Відповідність законодавству

  • RODO / GDPR — consent log, medical ACL (Art.9), 7-річний retention
  • Rozp. MEN 2016 — Karta Kwalifikacyjna (5 секцій), kurs wychowawcy 36h
  • Ustawa Kamilka 2024 — RPS перевірки, immutable incident ledger
  • EU Regulation 1169/2011 — 14 major allergens tracking
  • Załącznik 9 MEN — Program wypoczynku (required legal document)

Архітектура

  • «Hotel pattern» — один модуль, все в Python-файлах
  • Strangler Fig — поступова міграція з bs_campscout_addon без втрати даних
  • OCA-first — нативні Odoo модулі замість кастомних (loyalty, slide.channel, website_rating)
  • i18n — українська + польська через native Odoo .po файли
  • Безпека — OWASP Top 10, field-level ACL, record rules, audit trail
