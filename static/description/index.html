Odoo 17 Module

Fayna Camp Portal

Цілісне рішення для дитячих таборів у Польщі на Odoo 17. Один модуль містить усю логіку: бронювання, kartę kwalifikacyjną, dziennik zajęć, розклад дня, харчування з алергенами, протокол НС за Ustawą Kamilka, кабінет батька, навчання вихователів та інтеграції з SMS і Meta.

Ustawa Kamilka 2024

5-хвилинна ескалація НС, vital interest reporting, повний phone tree (medic / police / parent / kuratorium), audit-trail з IP та timestamp.

Karta kwalifikacyjna + Dziennik

Картка з 5 секціями (Rozp. MEN 30.03.2016), dziennik zajęć (Załącznik 5), Program Wypoczynku (Załącznik 9). Immutability після підпису, auto-refusal без картки за 24 год до заїзду.

📊

Admin dashboard + RODO art. 30

Camp-centric drill-down, view-as інших ролей для діагностики доступу, append-only timeline доступу до особових даних дитини.

👨‍👩‍👧

Кабінет батька /my/

Картка дитини, новини з табору, фото, програма лояльності (через loyalty), розстрочки, трансфер, відгуки.

🌍

UA / PL native i18n

Source EN, i18n/uk_UA.po + i18n/pl_PL.po. Без власної translation logic — усе через Odoo _().

Сценарій

Як працює

1
Бронювання заїзду

Батько обирає табір (product.template) і дату заїзду (event.event), оформлює замовлення через sale.order + event.registration. RODO-згода фіксується автоматично.

2
Підпис картки кваліфікації

У кабінеті /my/ батько заповнює медичну частину (Section II-V). Section I — readonly metadata події. Підпис → immutability lock. Без картки за 24 год до заїзду — auto-cancel + повернення коштів.

3
Заїзд і табір

Kierownik бачить qualified-список, призначає вихователів і кімнати. Розклад дня (Plan A / Plan B сонце-дощ) рендериться у timeline. SMS-сповіщення батькам про прибуття.

4
Щоденний журнал

Wychowawca веде dziennik zajęć (Załącznik 5), фіксує відвідуваність, харчування з EU-14 алергенами, інциденти. Усе видно батьку у real-time через /my/.

5
Виїзд + відгуки + лояльність

Після заїзду батько залишає відгук (через website_rating), отримує бали лояльності, запрошення на наступний сезон. PDF-snapshot картки і журналу зберігається 7 років (PL retention).

Право

Відповідність польському законодавству

📝
Rozporządzenie MEN z 30.03.2016

Karta kwalifikacyjna uczestnika — усі 5 секцій реалізовано як окремі моделі з правильним власником: Section I на event/camp, Section II-V на camp.participant.

🏢
Załącznik 1 — Zgłoszenie do Kuratorium

Автоматичне формування і подання сповіщення до Kuratorium Oświaty за 21 день до заїзду, з документацією харчування, програми, кадру.

📖
Załącznik 5 — Dziennik zajęć

Електронний журнал з append-only записами, розкладом дня, відвідуваністю, обов'язковим підписом kierownika перед закриттям зміни.

📚
Załącznik 9 — Program Wypoczynku

Структурований опис програми, активностей, виховних цілей. PDF-генерація для kuratorium та контрольних органів.

⚠️
Ustawa Kamilka 2024 — vital interest

Протокол НС з SLA 10s / 2min / 15min / 30min / 24h / 21d, action types, phone tree (medic / police / parent / kuratorium). Bypass RODO consent на основі art. 6(1)(d) RODO — ratowanie życia.

🛡️
RODO art. 9 — medycyna i alergii

Field-level groups на special-category health data. Доступ — тільки medic + kierownik. Audit timeline у admin dashboard. 7-річний retention за PL law.
