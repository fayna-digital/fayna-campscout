# ТЗ — канонічна анкета кадри (генератор договору) · v1

**Статус:** ЗАТВЕРДЖЕНО власником 2026-08-01 — обсяг «повний канон» (3.1–3.4)
**Дата:** 2026-08-01
**Файл-предмет:** `static/src/kadry/campscout.html` + `static/src/kadry/kadry_browser_campscout.js`

## 1. Навіщо

Анкета кадри — не проста форма, а генератор **шести документів** для працевлаштування
виховника/інструктора [ПЕРЕВІРЕНО: інвентар `docDefAll` у `kadry_browser_campscout.js`]:

| Документ | Тип |
|---|---|
| `UMOWA ZLECENIA` | договір |
| `KWESTIONARIUSZ OSOBOWY` | анкета |
| `KLAUZULA INFORMACYJNA RODO` | інформаційна клаузула |
| `OŚWIADCZENIE ZLECENIOBIORCY (ZUS/US)` | заява |
| `UPOWAŻNIENIE DO PRZETWARZANIA DANYCH OSOBOWYCH` | уповноваження |
| `ДОГОВІР ПРО ВОЛОНТЕРСЬКУ ДІЯЛЬНІСТЬ` | договір (UA) |

Мета: звести три розбіжні версії в одну, довести її до рівня еталона й **зафіксувати як канон**,
з якого далі виростає форма в модулі порталу таборів.

## 3. Обсяг робіт

### 3.1 Злиття (обов'язково — інакше регрес)
- База — локальна двомовна версія (найповніша за змістом).
- Перенести з серверної: POST перед `download()`, перевірка `resp.ok`, локальна копія
  з тих самих байтів, червоне повідомлення при відмові сервера.
- Підключити `assets/draft_beacon.js` — слід тих, хто почав і не закінчив.

### 3.2 Канон стилю
- Винести спільний CSS у `static/src/kadry/assets/forms.css` — зараз стилі дублюються
  в кожному з чотирьох HTML [ПЕРЕВІРЕНО: `ls assets/` — там лише JS].
- Анкету кадри привести до візуальної системи `zwrot.html`.
- Мобільний рендер перевіряти через WKWebView, не headless Chrome
  (пор. [[feedback_mobile_render_check_wkwebview_not_chrome_headless_2026-07-31]]).

### 3.3 Виправлення, знайдені аналізом коду
| Проблема | Що робимо |
|---|---|
| PESEL / РНОКПП / IBAN перевіряються лише на наявність | валідація формату + контрольної суми, з поясненням помилки |
| помилка надсилання гине в `console.warn` | видиме червоне повідомлення (як у `wilcza`) |
| «Заповніть обов'язкові поля» без вказання поля | підсвітка конкретного поля + прокрутка до нього |
| дати й ставки зашиті в коді | винести в один блок констант зверху |
| прогрес втрачається при закритті | маячок + відновлення з `localStorage` |
| спрощена транслітерація UA→LAT | таблиця за нормою для документів |

### 3.4 Тести (той самий набір, що закрив форми zwrot/RODO 01.08)
Реальний iOS-двигун (WebKit); обрив сторінки одразу після кліку; натовп одночасних сесій;
повільна мережа; перевірка, що всі шість PDF генеруються і доходять на сервер.

## 4. Межі
- **Не** переносимо форму в QWeb-шаблон Odoo на цьому кроці: вона має працювати без логіну.
  Портал підключить її пізніше, узявши цей файл як канон.
- **Не** чіпаємо решту форм, окрім винесення спільного CSS.
- Прод не зачіпається — форми свідомо живуть на staging (рішення власника на 2026 рік).

## 5. Рішення власника (2026-08-01)
1. **Підпис пальцем — НЕ додаємо.** Підпис лишається від руки після друку; юридична
   природа `UMOWA ZLECENIA` не змінюється. `canvas` у цю форму не вводимо.
2. **Обсяг — повний канон** (3.1–3.4).

## 6. Приймання
- Усі шість документів генеруються з коректними даними у двох мовах.
- З iPhone подання доходить на сервер; при збої користувач бачить помилку, а не «Дякуємо».
- Незавершене заповнення лишає слід у `[DRAFT-LOG]`.
- Спільний CSS підключений у всіх чотирьох формах, вигляд не поїхав.
