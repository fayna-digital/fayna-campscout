# Портал CampScout — Інструкції користувачів

**Версія:** 17.0.2.0.0 | **Мова:** Українська | **Остання оновлення:** 2026-06-10

Цей документ описує, **як користуватися** системою CampScout для кожної ролі. Вибери свою роль з меню нижче.

---

## Для кого це

У системі 7 основних ролей. Кожна роль має свої дозволи та функції:

| Роль | Французька | На что може | Де його меню |
|---|---|---|---|
| **Організатор** | Organizator Wypoczynku | Повна контроль: табори, бюджет, персонал, дозволи | `/admin/dashboard` |
| **Керівник табору** | Kierownik | Контроль групи, затвердження карток, доповіді | «Operacje» → «Dziennik dnia» |
| **Вихователь** | Wychowawca | Ведення дітей у групі, заповнення картки | Групи + записи |
| **Батько** | Parent (Portal User) | Переглід дітей, лояльність, документи | `/my/` — кабінет |
| **Інструктор** | Instructor | Програма заходів, дневник занять | Мої активності |
| **HR-менеджер** | HR Manager | Сертифікати персоналу, кваліфікація | «Szkolenia» |
| **Адмін операцій** | Admin Operacyjny | Звіти, бюджет, статистика | «Finanse» |

---

## Як отримати роль

1. **Для нового юзера:** адміністратор (Організатор) заходить до `/admin/dashboard`
2. Клікає **«Додати користувача»**
3. Заповнює:
   - Ім'я та прізвище
   - Email (логін)
   - Роль (Group)
4. Натискає **«Зберегти»**

Новий юзер отримає email із паролем.

---

## Структура табору

Кожен табір має:

- **Назва** — название програми (например, «Letni obóz 2026»)
- **Дати** — від якого числа до якого
- **Місце** — селище, область
- **Групи** — поділ дітей (типово 15-20 дітей / gruppo)
- **Персонал** — вихователі, інструктори, керівник
- **Програма** — розклад занять (Załącznik 9)
- **Бюджет** — витрати, ціна за дитину

## Навігація в системі

**Як потрапити до системи:**

1. Заходиш на https://campscout.eu/ (або admin-частину)
2. Клікаєш на своє ім'я у правому верхньому куті
3. Вибираєш свою роль (якщо їх кілька)
4. Потрапляєш у основне меню

**Основне меню (ліва колонка):**

```
Portal CampScout
  ├─ Obozy (табори)
  ├─ Uczestnicy (діти)
  ├─ Operacje (персонал, звіти, дневники)
  ├─ Żywienie (харчування)
  ├─ Sytuacje nadzwyczajne (надзвичайні ситуації)
  ├─ Sprzedaż (продажи, знижки)
  ├─ Szkolenia (курси, сертифікати)
  └─ Finanse (бюджет, дозволи фінансам)
```

## Спільні дії

### Як зберегти задачу

1. Заповни потрібні поля
2. Натисни **«Зберегти»** (або **Ctrl+S**)
3. Система покаже зелене повідомлення «Справа збережена»

### Як скасувати дію

1. Натисни **«Скасувати»** (на гарячому)
2. Все повернеться до попереднього стану

### Як шукати

1. На будь-якому списку (наприклад, списку дітей) є поле пошуку вгорі
2. Почни писати ім'я чи дату
3. Натисни **Enter**

### Як фільтрувати

1. Клікни на **«Фільтри»** вгорі списку
2. Додай умови (наприклад, «Статус = активна»)
3. Натисни **«Застосувати»**

## Знаходження помилок

**Якщо щось не працює:**

1. Прочитай червоне повідомлення про помилку внизу екрану
2. Перевір, чи заповнив усі обов'язкові поля (позначені зірочкою *)
3. Спробуй оновити сторінку (**F5**)
4. Якщо помилка залишається — зв'яжись з адміністратором

**Обов'язкові поля**: мають червону зірочку * біля названия.
