# Батько — Кабінет у портали

**Роль:** Parent (батько, опікун)

Батько — це особа з батьківськими правами. Має доступ до портали для перегляду дітей, отримання новин від табору, оплати.

---

## Як отримати доступ

Коли реєструєш дитину на табір, система автоматично:
1. Створює акаунт батька
2. Відправляє email із логіном/паролем
3. Батько входить на campscout.eu

---

## Перший вхід

1. Йдеш на https://campscout.eu
2. Клікаєш **«Увійти»** (Login)
3. Вводиш email + пароль
4. Потрапляєш до **Кабінету клієнта** (/my)

## Крок 1: Підпис картки (ОБОВ'ЯЗКОВО!)

**Коли реєструється дитина, батько повинен підписати картку.**

Ти отримаєш email: **«Підпиши картку дитини Анни»**

1. Клікни посилання у листі
2. Потрапляєш на `/my/participants/<id>/sign`
3. На екрані каркас для підпису

```
┌─────────────────────────────────────┐
│  Картка кваліфікаційна Анни         │
├─────────────────────────────────────┤
│                                     │
│  Дані дитини:                       │
│  • Прізвище: Коваль                 │
│  • Ім'я: Анна                       │
│  • Дата народження: 15.06.2013      │
│  • Табір: Летний лагерь 2026        │
│                                     │
│  ✅ Я сходження й даю дозвіл        │
│                                     │
│  Підпис батька:                    │
│  ┌───────────────────────────────┐  │
│  │                               │  │
│  │    (малюй пальцем)            │  │
│  │                               │  │
│  └───────────────────────────────┘  │
│                                     │
│  [Підпиши]  [Скасувати]             │
│                                     │
└─────────────────────────────────────┘
```

### Як підписати

1. **На комп'ютері:** мишкою малюй підпис у полі
2. **На планшеті/телефоні:** пальцем малюй підпис
3. Натисни **«Підпиши»**
4. ✅ Готово! Картка затверджена

⚠️ **Це юридичний документ!** Син міститьма дозвіл батька й не може бути змінений.

## Крок 3: Дневник дня (Dzień w obozie)

Меню: **«Щоденні історії»** (Stories)

Видно записи від **вихователя** кожный день:

```
День 1 — 15 липня
─────────────────
Погода: Сонячно, 22°C

Ранок: Адаптація, гра «Зоопарк»
Полудень: Плавання у озері
Вечір: Костер, пісні

Висновок: "Всі діти адаптувалися чудово! 
Анна швидко познайомилась з grupą."

Автор: Марія (Вихователь)
```

**Це автоматично оновлюється кожен день!**

## Крок 4: Лояльність (Program rabatowy)

Меню: **«Лояльність»** (Loyalty)

Видно:

```
Анна - Срібний рівень
─────────────────────
Знижка: 5%

Прогрес до наступного рівня (Золотий):
████████░░ (8 з 10 таборів пройдено)

Рівні програми:
🥉 Бронза   0% знижка   (0-2 табори)
🥈 Срібло   5% знижка   (3-5 таборів)  ← Ти тут
🥇 Золото  10% знижка  (6-9 таборів)
⭐ Платинум 15% знижка  (10+ таборів)
```

Поля знижка на наступный табір автоматично!

## Крок 5: Оплата

### При реєстрації дитини

1. Система показує ціну: **1200 zł**
2. Натискаєш **«Оплатити»** або **«Розстрочка»**
3. Йдеш на сторінку оплати (через PayU чи карту)
4. Вводиш дані карти
5. ✅ Готово!

### Розстрочка (raty)

Якщо в тебе немає всіх грошей:
1. Натисни **«Розстрочка»**
2. Вибери кількість місяців (3, 6, 12)
3. Система розподілить суму (напр., 1200 zł / 3 міс = 400 zł/міс)
4. Кожного місяця буде SMS з нагадуванням

⚠️ **ВАЖЛИВО:** якщо пропустиш платіж на 2 тижні — місцем дитини займе інша дитина!

## Крок 6: Документи

Меню: **«Документи»**

Видно **4 обов'язкових документа:**

| Документ | Що це | Статус |
|----------|-------|--------|
| **RODO (Дані)** | Дозвіл на обробку даних | ✅ Прочитаний |
| **Захист дитини** | Дозвіл на фото, відео | ✅ Прочитаний |
| **Регламент портали** | Правила користування | ✅ Прочитаний |
| **Умови продажу** | Договір купівлі-продажу | ✅ Прочитаний |

Всі документи мають бути **прочитані й затверджені** перед табором.

## Крок 7: Екстрені контакти

Де оновити номер телефону (батькові або опікуна):

1. Меню: **«Профіль»** (Profile)
2. Натисни **«Редагувати»**
3. Онови телефон
4. Натисни **«Зберегти»**

**Це дуже важливо!** Якщо з дитиною щось трапиться, керівник табору мусить мати актуальний номер!
