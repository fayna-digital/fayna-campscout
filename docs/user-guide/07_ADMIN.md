# Адмін операцій — Інструкція

**Роль:** Camp Operations Admin / Camp Finance

Адмін операцій керує звітами, бюджетами, фінансовими показниками й загальною статистикою.

---

## Як отримати роль

Організатор додає тебе до групи:
- **Camp Operations Admin** — для операцій і звітів
- **Camp Finance** — для бюджету (тільки читання)

---

## Крок 1: Фінансовий дашборд

Меню: **Finanse** → **Budżety obozów (BEP / marże)**

Видно всі табори й їхні бюджети:

```
Летний лагерь 2026
──────────────────
Період: 15-25.07.2026

Дохід (Przychody):
  • Учасники      72 000 zł
  • Спонсорство    5 000 zł
  ────────────────────
  • ВСЬОГО:       77 000 zł

Витрати (Koszty):
  • Харчування    24 000 zł
  • Персонал      16 000 zł
  • Транспорт      8 000 zł
  • Комунальні     3 000 zł
  • Резерв         3 000 zł
  ────────────────────
  • ВСЬОГО:       54 000 zł

Прибуток (Zysk):
  = 77 000 - 54 000 = 23 000 zł

Маржа %:
  = (23 000 / 77 000) × 100 = 29.9%

Статус: ✅ ЗАТВЕРДЕНО
```

## Крок 2: Аналіз реальних витрат

Меню: **Finanse** → **Звіти** або **Витрати**

Видно фактичні витрати порівняно з бюджетом:

```
Бюджет vs. Реальність
──────────────────────
Харчування:
  • Бюджет:       24 000 zł
  • Фактично:     23 500 zł
  • Різниця:      -500 zł (економія) ✅

Персонал:
  • Бюджет:       16 000 zł
  • Фактично:     16 500 zł
  • Різниця:      +500 zł (перевищення) ⚠️

Транспорт:
  • Бюджет:        8 000 zł
  • Фактично:      8 200 zł
  • Різниця:       +200 zł ⚠️

Прибуток:
  • Планований:   23 000 zł
  • Реальний:     22 800 zł
  • Різниця:      -200 zł
```

---

## Крок 3: Категорії витрат

Меню: **Finanse** → **Kategorie kosztów**

Тут видно всі можливі категорії витрат. Можна додати нові:

1. Натисни **«Додати»**
2. **Назва:** Новая категория, наприклад, «Страхування»
3. **Код:** Для бух. облику, наприклад, «INS-001»
4. **Опис:** Що включає (страхування дітей, персоналу)
5. Натисни **«Зберегти»**

## Крок 5: Експорт звітів

На будь-якій сторінці звіту:

1. Натисни **«Експортувати»**
2. Вибери формат:
   - **Excel** — для обробки в табличном редакторі
   - **PDF** — для друку й архіву
   - **CSV** — для імпорту в інше ПЗ
3. Файл завантажується на комп'ютер

## ⚠️ Важливі правила

1. ✅ **Контроль бюджету** — витрати не мають перевищувати на >10%
2. ❌ **Мінімальна маржа** — має бути ≥15% як резерв
3. 📄 **Документи** — всі витрати повинні мати квитанції
4. 🔒 **Зарплатні рядки** — видна тільки тобі й Організаторові
5. 📊 **Експорт** — експортуй звіти регулярно для архіву
