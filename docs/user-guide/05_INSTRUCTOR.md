# Інструктор — Інструкція

**Роль:** Camp Instructor (спеціаліст активності)

Інструктор — це особа, яка проводить спеціалізовані заняття (плавання, архерія, клімбінг, тощо) для однієї чи кількох групи.

---

## Як отримати роль

Керівник табору:
1. Меню: **Operacje** → **Kadra** → **Додати**
2. Вибирає твоє ім'я
3. Вибирає **активність** (Плавання, Архерія, тощо)
4. Натискає **«Зберегти»**

---

## Що видишь у системі

1. **Твої заняття** — розклад, коли вишільний
2. **Дітей по активностям** — хто приходить на твоє плавання
3. **Медичні потребі** — алергія, якщо релевантна (не всі дані)

---

## Крок 1: Переглід розкладу

Меню: **Operacje** → **Dziennik zajęć**

Видно твої заняття:

```
Мій розклад
────────────
15.07 — 10:00: Плавання для Групи А (18 дітей)
15.07 — 14:00: Плавання для Групи Б (17 дітей)
16.07 — 10:00: Плавання для Групи А (18 дітей)
```

---

## Крок 2: Проведення заняття

### Перед заняттям

1. Переглй список дітей
2. Перевір алергію (якщо релевантна, напр., для плавання не показується)
3. Надінь форму відповідальності (підпис перед дітьми)

### Під час заняття

Займайся своєю активністю, спостерігай за дітьми.

### Після заняття

1. Натисни **«Додати запис»** у дневнику занять
2. Заповни:

| Поле | Приклад |
|------|---------|
| **Дата** | 15.07.2026 |
| **Час** | 10:00-11:30 |
| **Активність** | Плавання |
| **Присутні** | 18 з 18 |
| **Хід заняття** | Розминка (5 хв), техніка дихання (20 хв), вільне плавання (20 хв), розтягування (5 хв) |
| **Особливі примітки** | Петро дуже боїться води, показав дуже малий прогрес. Може бути потрібна робота 1-1 або психолог. |
| **Матеріали** | Жилети, маски, буї |
| **Оцінка** | ⭐⭐⭐⭐ (добре, але потребує роботи над страхом) |

3. Натисни **«Зберегти»**

---

## Крок 3: Проблеми під час заняття

### Якщо дитина захворіла

1. Скажи **Вихователю групи**
2. Вихователь відведе дитину до медичного офіцера

### Якщо дитина поранилась

1. **МИТТЄВО** надай першу допомогу
2. Викличи **Керівника табору**
3. Якщо серйозна травма (перелом, кровотеча) — викличи скорою (112)
4. Керівник заповнить інцидент

### Якщо дитина не хоче робити вправи

- Спробуй переконати
- Якщо відмовляється — скажи **Вихователю**
- Вихователь поговорить з дитиною приватно
- Напиши про це у дневнику занять

---

## Крок 4: Сертифікаційна перевірка

**Перед табором система перевірить твою кваліфікацію.**

Меню: **Szkolenia** → **Rejestr szkoleń**

Система покаже:
- ✅ Які сертифікати у тебе є
- ❌ Яких не вистачає

Приклад:
```
Сертифікати Петра Смика
────────────────────────
✅ Сертифікат інструктора плавання (до 30.06.2027)
✅ Першої допомоги (до 31.12.2026)
❌ Відсутня: Сертифікат безпеки на водоймі

Статус: ⚠️ НЕПОВНИЙ — не можеш вести заняття плавання!
```

Якщо щось не вистачає — повідом **Керівника табору** або **Організатора**.

---

## Крок 5: Передача інформації про вихованців

Видишь **алергію** дітей (якщо релевантна для твої активності):

Приклад для Інструктора плавання:
```
Дітьми з моєї групи:
─────────────────────
1. Анна Коваль — астма (потребує ліків, не піддається гіпервентиляції)
2. Петро Сич — страх води (психологічна робота)
3. Юля Мартинес — наркоз (через алергію на хлор?)
```

⚠️ **Конфіденційно!** Не розповідай іншим дітьми про здоровіе однокласниці.

---

## ⚠️ Важливі правила

1. ✅ **Веди дневник** після кожного заняття
2. ❌ **Не видаляй записи** — це документ
3. 🔒 **Медичні дані** — конфіденційно
4. 📞 **Контакт** із Керівником табору — для проблем
5. ⚠️ **Травми** — негайно повідом Керівника
